# SqlPilot

ابزار تکمیل و کمک به برنامه‌نویسی SQL در **SQL Server Management Studio**.

سازنده: **Arash Ghasemi Rad** — [تلگرام @ArashGhasemiRad](https://t.me/ArashGhasemiRad)

[راهنمای کامل انگلیسی](README.md) · [دریافت نسخه‌ها](https://github.com/tyeety/SQLPilot/releases) · [مجوز](LICENSE)

## نصب

۱. فایل `SqlPilotSetup-0.13.2.exe` را از Releases رسمی دریافت کن.

۲. کوئری‌ها را ذخیره کن؛ برای آماده‌سازی نصب می‌توانی SSMS را باز نگه داری.

۳. نصاب را اجرا کن، نسخه‌های مورد نظر را انتخاب کن و نصب را انجام بده. نصب میزبان به دسترسی Administrator نیاز دارد.

۴. اگر SSMS باز است، آن را بعد از آماده‌سازی ببند و منتظر پایان نصب بمان. با دکمهٔ Open SSMS نسخهٔ دلخواه را باز کن؛ در تب کوئری متصل، دکمهٔ **SqlPilot** را در نوار ابزار پیدا کن.

نصاب نسخه‌های موجود و وضعیت Upgrade، Reinstall یا Downgrade را نشان می‌دهد. برای بازگشت به نسخهٔ قدیمی هشدار دارد و از نصب قبلی پشتیبان می‌گیرد. فایل نصاب فعلاً امضای دیجیتال ندارد؛ فقط نسخهٔ رسمی و هش اعلام‌شده را بررسی کن.

## امکانات

- پیشنهاد جدول، ستون، اسکیما، تابع و پارامترهای Stored Procedure با فیلتر تلفیقی و alias.
- پیشنهاد JOIN و شرط ON براساس foreign keyهای قابل مشاهده، شامل روابط چندستونی.
- تبدیل `*` در بخش SELECT به ستون‌های زیر هم با Tab، همراه راهنمای کوچک در ویرایشگر.
- شورتکات‌های قابل تغییر، اسنیپت‌هایی مثل `ssf`، خطا و هشدار با توضیح و اصلاحات امن.
- مرتب‌سازی با حفظ کامنت‌ها، تبدیل عملگرهای اشتباه، کتابخانهٔ SQL با دسته‌بندی و جستجو، هیستوری و بازیابی تب‌ها.

Ctrl+Space پیشنهادها را باز می‌کند؛ Tab/Enter تأیید می‌کند و Esc می‌بندد. Alt+Enter یا Ctrl+. توضیح خطا و اصلاحات را نشان می‌دهد. Ctrl+Shift+F برای مرتب‌سازی، F12 برای رفرنس و Ctrl+F12 برای Object Explorer است. همهٔ کلیدها در Keyboard shortcuts قابل تغییرند.

رابط ابزار و نصاب انگلیسی است. نسخهٔ فعلی **0.13.2** است و اتصال AI/Codex ندارد. پیشنهادها و بررسی‌ها محلی‌اند؛ اصلاحات و اسکریپت رفرنس فقط متن ویرایشگر را تغییر می‌دهند و SQL اجرا نمی‌کنند. اطلاعات و فایل‌های کاربر زیر `%LOCALAPPDATA%\SqlPilot` نگه‌داری می‌شوند؛ متن و کانکشن سشن با DPAPI حساب ویندوز محافظت می‌شوند. فایل‌های Library و History ممکن است SQL حساس داشته باشند و باید دسترسی به آن‌ها را محافظت کرد.

## سازگاری و ساخت

ساخت آداپترها روی SSMS 20 و 22 بررسی شده است؛ تضمین همهٔ نسخه‌های قدیمی یا آینده وجود ندارد. دسترسی به متادیتا، روش اتصال و API میزبان روی عملکرد اثر می‌گذارد. جزئیات در [راهنمای ساخت](docs/BUILDING.md) و [وضعیت تست](docs/VALIDATION.md) آمده است.

برای ساخت روی ویندوز با .NET 8 SDK و میزبان نصب‌شده:

```powershell
pwsh -File scripts/Test.ps1
pwsh -File scripts/Build.ps1
pwsh -File scripts/Build-Setup.ps1
```

## نصب در زمان باز بودن SSMS

در نسخهٔ 0.13.2 می‌توانید SSMS را باز نگه دارید. نصاب به‌جای متوقف کردن نصب، فایل‌ها را آماده می‌کند و وضعیت **Prepared · restart required** را نشان می‌دهد. پس از ذخیرهٔ کوئری‌ها و بستن عادی تمام پنجره‌های همان نسخه، نصب در پس‌زمینه انجام می‌شود. تا پایان نصب SSMS را باز نکنید. سپس دکمهٔ **Open SSMS** نسخهٔ موردنظر را باز می‌کند. این دکمه SSMS را با سطح دسترسی معمول کاربر اجرا می‌کند.

بستن نصاب انتظار پس‌زمینه را متوقف نمی‌کند؛ **Cancel pending** فقط عملیات هنوز منتظر را لغو می‌کند. ویندوز را تا پایان نصب روشن نگه دارید؛ انتظار حداکثر ۲۴ ساعت است و پس از ری‌استارت ویندوز باید نصاب را دوباره اجرا کنید. وضعیت نهایی در `%LOCALAPPDATA%\SqlPilot\PendingSetup\<job>\status.json` ثبت می‌شود. نصاب تب‌های SSMS را نمی‌بندد.

پیام SmartScreen به علت نبود امضای دیجیتال معتبر و شهرت کافی فایل است. نصاب حفاظت ویندوز را غیرفعال نمی‌کند. امضای معتبر نیازمند گواهی ناشر است و حذف تمام هشدارهای SmartScreen را تضمین نمی‌کند. فایل را از ریلیز رسمی دریافت کنید و SHA-256 آن را بررسی کنید.
