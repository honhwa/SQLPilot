# SqlPilot icon

Original vector mark: a turquoise database cylinder, a white completion chevron, and a small lime spark on a dark navy rounded tile. The cylinder communicates SQL metadata; the chevron and spark communicate typing assistance. No text is included so the icon remains legible at 16px.

The design is authored in SVG and deterministically rendered with WPF into a transparent 256px PNG and a Windows ICO containing 16/24/32/48/64/128/256px frames. No generated image model was used. The ICO is embedded as the setup executable's application icon, and the PNG is embedded in each compiled editor adapter.
