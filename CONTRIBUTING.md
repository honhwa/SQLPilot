SqlPilot is maintained by Arash Ghasemi Rad. Its source is published for inspection and use under [LICENSE](LICENSE), which does not grant permission to modify or redistribute the code.

Bug reports and feature requests are welcome through [GitHub Issues](https://github.com/tyeety/SQLPilot/issues). Include the SqlPilot and SSMS versions, reproduction steps, expected behavior and an anonymized SQL example when needed. Remove server addresses, credentials and private database information.

Do not submit modified-code pull requests without prior written permission. Contact [@ArashGhasemiRad](https://t.me/ArashGhasemiRad) to discuss patches, reuse, redistribution or commercial licensing. If permission is granted, preserve author and third-party notices, apply the repository formatting rules, and run the relevant tests before proposing changes.
